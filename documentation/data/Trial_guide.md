# What you can test before deploying changes

Below are some preset users by role (password same as username):
IA (reg1)
Senior II (sgt1)
II(user1, user2, user3, eldon)

# Send Parade State and json tasks 
1. Log in as reg1 (pass: reg1)
2. Set display dates to feb 2 - feb 7
3. Go to 'Uploads' at the navigation bar
4. Upload a parade state csv from "sample ps" folder
5. Upload a json file from "dummy_data" folder (ranges from feb 2 to feb 7)
6. Click "Upload" 

By default, the tasks are automatically assigned to users but can be changed in Tasking Manager

# Mark tasks as started/ ready for vetting
1. Log in as user with II role (works for any other role but reaalistically to be done by II)
2. Set display dates to feb 2 - feb 7
3. Go to 'Tasking Summary' at the navigation bar
4. Immediate in view are the images with tasks/areas assigned to you
5. Click ONLY the areas/tasks you want to start
6. Click "Start Task"
7. When done labelling task/area, click "Complete Task" to show that it is ready for vetting by Senior II

# Vetting
1. Log in as user with Senior II role (works for IA but realistically to be done by Senior II)
2. Set display dates to feb 2 - feb 7
3. Go to 'Tasking Summary' at the navigation bar
4. After verifying, click "Verify Pass" or "Verify Fail". If pass, then the task/area is marked as complete
5. When all tasks/areas done for an image, click "Complete Image" to mark the whole image as completed. It is shown to be done in "Completed" Images
